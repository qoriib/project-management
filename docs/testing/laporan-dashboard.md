## Catatan Penguji

- Tanpa Tauri, DB kosong — empty state terverifikasi via browser.
- Export memerlukan `@tauri-apps/plugin-dialog` + `fs` — tidak dapat diuji via Playwright browser, ditandai `—`.
- Perbaikan summary card: 3 card paralel (Direncanakan, Dipesan, Selisih) dengan struktur konsisten, border, badge, dan warna hierarki (lihat `ReportSummaryCards.tsx`).
